# Sovereign Stars documentation assets

These files are retained for README/documentation screenshots and visual examples only.
They are documentation assets, not executable audit inputs, and must not be referenced by
E2E evidence.

- `source-assets/` contains the source text/images used for documentation examples.
- `epub/` contains the generated EPUB used for screenshots/examples.

Requirement-derived audit inputs are generated by `tests/audit_support/epub.rs`; the only
repository fixture consumed by that suite is the explicitly documented embedded-font asset.
